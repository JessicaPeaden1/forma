QuickBooks DesktopIn Transition
ERP / Finance / Inventory
Core accounting and ERP backbone. Handles multi-site consignment inventory, A/P, A/R, COGS. Hosted on remote server — adds integration friction. Andrew called it "terrible" and "too slow to scale." Still active because it supports complex inventory needs. No automation should be built here until ERP direction is confirmed. BUILD GATE
Google Sheets (CRM)Active
CRM / Sales Tracking / Customer Data
Replaced Nutshell CRM after adoption failure. Manually updated weekly by 2 employees aggregating input from ~45 distributors. Tracks surgeons, reps, territories, surgery pipeline, cohorts, weekly sales targets. Works operationally today. Not scalable long-term. Google API available for future integration.
DropboxActive
Document Management
Highly organized folder tree — SOPs, pricing files, contracts, account info, operational docs. Andrew calls it a "strategic asset." Not AI-indexed or searchable. Dropbox API available. Andrew explicitly wants this connected to the BI/AI layer. During a prior acquisition, Dropbox's organization proved its value.
GmailActive
Email / Operations Trigger
Case sheets and hospital POs from 1099 reps arrive via Gmail and are manually entered into ERP. This is the order-to-cash trigger. Andrew called it "marginally important" — this is a scope conflict. Gmail is the operational entry point for the entire revenue cycle. Gmail API available. SCOPE CONFLICT

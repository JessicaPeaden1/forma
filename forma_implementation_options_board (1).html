#3 — Surgery Tracking System Identity

#5 — Weekly Review Data Schema
Required to build the automated weekly business review workflow. Without the exact fields, metrics, and sources Andrew pulls each week, no data pipeline can be designed. Owner: Andrew.
🟡
#6 — Permission Tier Definitions
Three conceptual tiers were proposed but never formally defined. Must be confirmed before BI architecture is scoped — affects what AI agents can see and surface. Owner: Andrew.

#7 — BI Output Spec

Andrew's primary AI tool has no known API integration. Any multi-model architecture must work around this or find an alternative. LangChain routing (Option 3/4) is the current workaround strategy. Owner: Jessica + Andrew.
